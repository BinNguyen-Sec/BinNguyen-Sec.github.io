# BINNGUYEN-SEC Portfolio

Production cybersecurity portfolio for Bin Nguyen.

## Stack

- React
- TypeScript
- Vite
- Framer Motion
- React Router
- GitHub Pages
- GitHub Actions

## Resume

The live portfolio provides two downloadable PDF resume versions:

- English: `/resume/Nguyen-Ngoc-Khai-Resume-English.pdf`
- Tiếng Việt: `/resume/Nguyen-Ngoc-Khai-Resume.pdf`

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deployment

Pushes to `main` trigger the GitHub Pages workflow in `.github/workflows/deploy-pages.yml`.
